# أنواع الأعطال وشلون نتعامل وياها

| العطل | التعامل |
|---|---|
| النموذج ما يرد، أو مشغول (503)، أو وصل حد الاستخدام (429) | الخادم ينتظر مكان تحت حد الدقيقة بدل الخطأ، بعدها النموذج الثاني (أو Groq)، بعدها المحلل الثابت والقوالب. كلشي يبقى يشتغل |
| الوكيل يدور بحلقة أو يطلب أدوات بلا نهاية | يوقف بعد 5 أدوات ويجاوب سير العمل الثابت |
| الوكيل يطلب أداة كتابة أو دفع | تنمنع وتظهر بالخطوات، وماكو شي ينكتب |
| الصوت انسمع غلط | «سمعتك: … صح؟» قبل أي تنفيذ، وتگدر تصحح النص |
| الصوت انكتب بالفصحى بدل اللهجة («اش قد» بدل «شكد») | Gemini أول محرك للصوت، وتصحيح ثابت يرجّع الكلمات لشكلها العراقي |
| النموذج يخترع رقم أو ينسى الرقم الأساسي | المدقق يرفض الجواب، والسبب يظهر بـ«خطوات الوكيل» |
| النموذج ينسب كلام لزبون («گالت رح تدفع») أو يگول إنه سوّى شي | المدقق يرفضه، لأن الدفتر ما بيه أي رد من الزبون، والمساعد ما يرسل شي بدون موافقتك |
| أمر انفهم غلط (مثلاً الصوت انسمع «سجل» بدل «ذكّر») | كل أمر يطلع كبطاقة، وما ينرسل إلا لما تضغط «أرسل» |
| النموذج يرجع أداة أو زبون مو موجود | التوجيه ينرفض ويشتغل المحلل الثابت |
| النموذج يرفض سؤال واضح من شغل المحل («شكد بالمخزن؟») | إذا المحلل الثابت لگى سؤال مخزون أو زبون أو طلبية، هو يجاوب، والسبب يطلع بالخطوات |
| تكملة بدون اسم («ذكّرها»، «والبارحة؟»، «اطلب على أي حال») | المساعد يتذكر آخر زبون وآخر مورد وآخر سؤال. إذا ماكو شي قبلها، يسأل منو |
| أكثر من سؤال بنفس الجملة | الجملة تتقسم على أسئلتها (لحد 3)، وكل سؤال ياخذ جوابه |
| سؤال عن فترة أو زبون أو مادة ماكو | رفض واضح بدل تخمين |
| صورة دفتر ما تنقرا | ثقة لكل حقل، واللي تحت 70% ينعلم، والفارغ يبقى فارغ |
| الصوت ما ينفهم أو التفريغ فارغ | محاولة ثانية على المحرك الثاني، وبعدها رسالة «ما سمعت زين» |
| المتصفح ما بيه صوت عربي (Chrome على Windows) | الجواب ما ينقرا بصوت إنگليزي، ويطلع تنبيه «افتحه بـEdge» |
| مورد رفض أو وفّر نص الكمية | الطلبية تتعلم «توفر جزئي»، والمادة تبقى قليلة، فتنكتب طلبية جديدة بعدين |
| مورد رفع السعر بالفاتورة | تنبيه قبل الدفع، والدفع يبقى بيدك |
| كاش ما يطابق | التسكيرة تبين الفرق وأسباب محتملة، بدون اتهام |
| زبون ينكر الدين | الدين يحتاج تأكيد من محفظته، والاعتراض يطلع تنبيه |
| تحويل وارد بدون اسم | يطلع بالتسكيرة، وتربطه بزبون بضغطة |
| محتال يتصل ويدّعي إنه من زين كاش، أو المورد «غيّر رقمه» | فحص التحويل يطلع شاشة توعية، والإكمال يحتاج انتظار وتأكيد ورمز |
| تحويل سليم ياخذ تنبيه (رقم جديد لصديق) | تنبيه خفيف بس، وتكمل بضغطة. نقيس نسبته: 20% من التحويلات السليمة بالمجموعة المحجوبة |
